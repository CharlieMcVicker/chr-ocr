# Cherokee Phoenix OCR - Project & Directory Mapping

This file serves as the context mapping and reference manual for semantic and keyword search tools (like `ember` and `hyper-ember`) operating on the Cherokee Phoenix OCR repository.

---

## 1. Project Overview & Objective

The **Cherokee Phoenix OCR** project is a specialized OCR pipeline designed for high-fidelity digitization of historical Cherokee texts, specifically focusing on:
1. **Cherokee Phoenix Scans**: Historical newspapers with distinct, multi-column layouts and unique typography.
2. **Cherokee New Testament (CNT)**: Used as a training corpus and for advanced data augmentation strategies to boost recognition rates on historically degraded texts.

The system uses Tesseract LSTM-based OCR, PyTesseract, Surya (for layout/column detection), and OpenCV-based image binarization. It includes a training pipeline, a data augmentation pipeline (handling elastic transforms, ink bleed, and coarse dropout), and a web interface (Flask) for scanning and evaluation.

## 2. Directory & Component Mapping

### 📂 `phoenix/` (Core Modular Package)
This is the main python module housing library-level logic:
- **`phoenix/config.py`**: Defines hyperparameter schema, training configuration, noise/augmentation settings, and deserialization routines via Pydantic/dataclasses.
- **`phoenix/manifest/`**: Handles dataset manifest processing, label consolidation, manifest sanitization, line cropping, and split operations.
- **`phoenix/layout/`**: Implements document layout analysis, column detection using Surya, bounding box generation, and pyTesseract FTM (Font Type Metric) text extraction.
- **`phoenix/text/`**: Text-processing and normalization utilities for Cherokee characters.
- **`phoenix/training/`**: ML pipeline orchestrations, evaluation routines, custom LSTM training configurations, and stage loop structures.

### 📂 `scripts/` (Scripts & Experiments)
Contains utility scripts, training/evaluation wrappers, data scrapers, and experiment pipelines:
- **Core Pipelines & Entry Points**:
  - `train_staged.py`: The primary staged training script (runs network expansion, staged training epochs, and tracks best checkpoints).
  - `mix_datasets.py` & `sweep_mixture_ratios.py`: Handles Cherokee Phoenix and CNT dataset mixing/sweeping.
  - `process_all_scans.py` & `process_all_cnt.py`: Main processing pipelines for document scans and Cherokee New Testament sources.
- **Layout & Columns**:
  - `diagnose_columns.py`: For checking column bounding boxes and layouts.
  - `classify_layout.py`: Uses Surya layout analysis to segment lines and columns.
- **Augmentation & Noise**:
  - `augment_dataset.py` & `augment_dynamic.py`: Image degradation tools implementing elastic deformation, ink wash/smudge, coarse dropout, and pixel-level noise.
- **Evaluation**:
  - `evaluate_mixed_model.py`: Performs evaluations across multiple testing corpora.
  - `evaluate_checkpoints.py` & `generate_performance_graphs.py`: Scoring and checkpoint selection utilities.

### 📂 `backlog/` (Project Backlog & Decisions)
- **`backlog/tasks/`**: Active, pending, and complete project tasks managed via the `backlog` CLI.
- **`backlog/docs/`**: Comprehensive documentation, user guides, and research.
- **`backlog/decisions/`**: Architecture Decision Records (ADRs).

### 📂 `server/` (Web Application Interface)
- A Flask-based web application providing a frontend dashboard.
- Users can upload historical newspaper scans, perform interactive image binarization (Sauvola, Otsu), crop text lines, run Tesseract OCR, and view visual overlays of column segmentations.

## 3. Core Concepts & Terminology for Search Models

When searching for logic in this codebase, keep these key terms and files in mind:
- **Binarization**: OpenCV-based image preprocessing. Found in `server/` and `scripts/generate_binarization_graphs.py`.
- **Surya / Layout / Columns**: Layout analysis and column detection. Managed in `phoenix/layout/` and scripts like `diagnose_columns.py`.
- **CNT (Cherokee New Testament)**: Secondary dataset used for high-frequency noise injection.
- **Augmentation / Elastic / Ink Wash / Coarse Dropout**: Image-level degradation techniques found in `phoenix/training/` and `scripts/augment_dynamic.py`.
- **Best Checkpoint / Tracking**: Automatic tracking of best training checkpoints and evaluations in `train_staged.py`.
